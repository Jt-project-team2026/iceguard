# 상태머신 / 결빙 단계

## 결빙 단계 (ESP32에서만 계산)

| 단계 | 조건 |
|---|---|
| 안전 | 아래 조건에 해당하지 않음 |
| 주의 | 온도 ≤ 5℃ 그리고 습도 ≥ 70% |
| 위험 | 온도 ≤ 2℃ 그리고 습도 ≥ 70% |

## 열선 상태

| 현재 | 조건 | 다음 |
|---|---|---|
| OFF | 온도 ≤ 2℃ 그리고 습도 ≥ 70% | HEATING |
| HEATING | 온도 ≥ 5℃ | OFF |
| HEATING | 연속 작동 한도 초과 (실사용 10분, 시연 30초) | COOLDOWN |
| COOLDOWN | 휴식 시간 경과 (실사용 2분, 시연 10초) | OFF |
| 임의 | 센서 읽기 3회 연속 실패 또는 NaN, 패드 온도 ≥ 60℃ | FAULT |
| FAULT | 센서 정상 복구 | OFF |

## 이벤트 (서버가 이전 상태와 비교해 생성)

`HEATER_ON`, `HEATER_OFF`, `COOLDOWN`, `FAULT`, `RECOVERED`
